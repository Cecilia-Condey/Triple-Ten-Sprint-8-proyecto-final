# Triple-Ten-Sprint-8-proyecto-final

NovaRetail+ | Análisis del comportamiento de clientes

Descripción del proyecto

Análisis exploratorio y estadístico de un conjunto de datos de 15,000 clientes de NovaRetail+ correspondiente a 2024, con el objetivo de identificar los comportamientos asociados con los ingresos anuales generados.

Objetivo

Identificar qué variables de comportamiento presentan las asociaciones más relevantes con los ingresos anuales y traducir los resultados en recomendaciones de negocio.

Herramientas utilizadas

Python

Pandas y NumPy

Matplotlib y Seaborn

SciPy

Jupyter Notebook

Metodología

Exploración y validación de datos.

Análisis estadístico descriptivo.

Visualización de relaciones entre variables.

Correlaciones de Pearson y Spearman.

Correlación punto-biserial.

V de Cramér.

Interpretación de resultados y recomendaciones de negocio.

Principales hallazgos

Las compras mensuales presentan una asociación positiva muy fuerte con el ingreso anual (r = 0.9671).

Las visitas mensuales presentan una asociación positiva moderada (r = 0.3371).

El gasto en publicidad dirigida presenta una asociación positiva débil (r = 0.1975).

La membresía premium presenta una asociación muy débil, aunque estadísticamente significativa.

El abandono no presenta una asociación estadísticamente significativa con el ingreso anual.

Conclusiones

Los resultados destacan la importancia de la frecuencia de compra como variable asociada con los ingresos. También sugieren oportunidades para profundizar en la segmentación de clientes, la conversión y la evaluación de estrategias publicitarias.

Las asociaciones observadas no permiten establecer relaciones causales.
